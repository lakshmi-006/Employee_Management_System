# Employee Management System

## Introduction
A console-based Java application to manage employee details and calculate salaries for full-time and part-time employees.

## Features
- Add, view, update, and delete employee details
- Support full-time and part-time employees
- Calculate employee salaries
- Prevent duplicate employee IDs
- Validate user inputs

## Project Structure

```text
Employee_Management_System/
├── EmployeeManagementSystem.java
├── Employee.java
├── Fulltimeemployee.java
├── Parttimeemployee.java
├── .gitignore
└── README.md
```

## Class Description
- **Employee:** Stores common employee details and defines salary calculation.
- **Fulltimeemployee:** Handles full-time employee salary and annual bonus.
- **Parttimeemployee:** Calculates salary based on hourly rate and hours worked.
- **EmployeeManagementSystem:** Handles menu operations and employee management.
